# AI Doctor Virtual Medical Assistant

## Project Overview
Developed a comprehensive AI-powered virtual medical assistant that provides intelligent health consultations, medical image analysis, and automated prescription generation. The system combines conversational AI, computer vision, optical character recognition (OCR), and speech processing technologies to deliver a complete telemedicine solution.

## Key Features
- **Conversational AI Doctor**: Integrated with OpenAI's GPT models to conduct symptom-based consultations and generate medical advice
- **Medical Image Analysis**: Deep learning models (ResNet50) for automatic fracture detection in X-ray images of elbow, hand/wrist, and shoulder regions
- **Lab Report Processing**: OCR capabilities using PaddleOCR to extract and analyze medical test results from uploaded documents
- **Voice Interaction**: Speech-to-text conversion using OpenAI Whisper and text-to-speech synthesis using Google Text-to-Speech (gTTS)
- **Prescription Generation**: Automated creation of professional medical prescriptions in PDF format with structured data extraction
- **Web Interface**: Modern, responsive frontend built with HTML5, CSS3, and JavaScript for seamless user experience

## Technical Architecture
- **Backend**: FastAPI (Python) with asynchronous request handling and CORS support
- **AI/ML Models**: TensorFlow/Keras for computer vision, OpenAI API for language processing, Whisper for speech recognition
- **Data Processing**: Image preprocessing, text extraction from JSON/OCR outputs, PDF generation using ReportLab
- **Frontend**: Static web application with animated UI components and real-time chat interface
- **Deployment**: Uvicorn ASGI server for production-ready hosting

## Technologies Used
- **Programming Languages**: Python
- **Frameworks**: FastAPI, TensorFlow, Keras
- **Libraries**: OpenAI API, Whisper, gTTS, PaddleOCR, ReportLab, NumPy
- **Frontend**: HTML5, CSS3, JavaScript
- **Infrastructure**: File upload handling, session management, background task processing

## Impact
This project demonstrates expertise in full-stack development, AI integration, and healthcare technology.
